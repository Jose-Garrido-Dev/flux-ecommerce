# Categorías

**Para qué sirve:** organizar el catálogo en un árbol (ej.: *Ropa › Poleras*) para el menú, los filtros y las páginas de categoría.

## Campos
| Campo | Explicación |
| --- | --- |
| Nombre | Ej.: "Poleras" |
| URL amigable | `/categoria/poleras`. Se genera sola |
| Categoría superior | Déjala vacía para una categoría principal |
| Imagen y banner | Imagen cuadrada para tarjetas; banner ancho (1920 × 600) para la página |
| Ícono y color | Opcionales, para el menú |
| Estado | *Activa* o *Desactivada* (no se muestra en la tienda) |
| Orden | Posición dentro de su nivel. También puedes arrastrar en el listado |
| SEO | Título y descripción para Google |

## Crear, modificar y desactivar
- **Nueva categoría**, elige la superior si corresponde y guarda.
- Para moverla, cambia la categoría superior: sus subcategorías se mueven con ella.
- **Desactivar** la oculta de la tienda sin perder nada.
- **Mover productos** pasa todos sus productos a otra categoría (útil antes de eliminar).
- **Eliminar** solo funciona si no tiene productos ni subcategorías.

## Errores frecuentes
- *"Crearía un ciclo":* una categoría no puede quedar dentro de sí misma ni de una de sus subcategorías.
- *"Superaría los niveles":* el máximo es de niveles indicado bajo el campo.

## Recomendaciones
- Mantén pocas categorías principales (6 a 10) para que el menú sea claro.
- Usa marcas y atributos para filtrar en vez de crear categorías muy específicas.

## Relaciones con otros módulos
- **Productos** tienen una categoría principal y pueden estar en otras secundarias.
- **Importar productos** crea categorías con la ruta `Ropa > Poleras` si activas esa opción.
