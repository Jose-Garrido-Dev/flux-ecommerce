# Marcas

**Para qué sirve:** agrupar productos por fabricante, mostrarlas en la portada y permitir filtrar por marca.

## Campos
| Campo | Explicación |
| --- | --- |
| Nombre | Ej.: "Nike". No se repite aunque cambien mayúsculas, espacios o tildes |
| URL amigable | `/marca/nike` |
| Logotipo y banner | Logo cuadrado o apaisado con fondo transparente; banner 1920 × 600 |
| Sitio oficial, país | Informativos |
| Estado | *Activa* o *Archivada* (no se muestra; sus productos siguen visibles) |
| Mostrar en la portada | Aparece en la franja de marcas de la página de inicio |
| SEO | Título y descripción para Google |

## Crear, modificar y desactivar
- **Nueva marca**, completa y guarda. También se puede crear desde el formulario de producto.
- **Archivar** la oculta sin afectar a sus productos.
- **Eliminar** solo funciona si no tiene productos.

## Errores frecuentes
- *"Ya existe la marca…":* "nike", "Nike " y "NIKE" son la misma marca.

## Relaciones con otros módulos
- **Productos** tienen una marca.
- **Importar productos** crea marcas que no existen si activas esa opción.
